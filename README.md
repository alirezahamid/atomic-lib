## 🧪 Why Atomic Design?

Atomic Design is a methodology created by **Brad Frost** for creating design systems. Think of it like chemistry—atoms are the basic building blocks that combine to form molecules, organisms, templates, and pages.

### The Atomic Hierarchy

- **Atoms** → Basic HTML elements like buttons, inputs, labels
- **Molecules** → Simple combinations like search forms
- **Organisms** → Complex components like headers, product grids
- **Templates** → Page layouts without content
- **Pages** → Real instances with actual content
